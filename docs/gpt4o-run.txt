# Findings:
# - Schema access is the big win: baseline (no schema) 45%, schema-aware 85%. Without
#   the schema the model invents column names (10 of 20 come back schema_hallucination).
# - Agentic retry-on-error removes execution errors (schema_hallucination 1 -> 0) but
#   does NOT raise accuracy (still 85%): it turns a query that fails to run into one that
#   runs and is still wrong. Retry fixes execution, not correctness. Measured, not assumed.
# - Every wrong answer was held at high confidence (err@hi 100%; mean confidence on wrong
#   answers 0.97, higher than 0.96 on right ones). The model's confidence gives a business
#   user no warning. This is the failure the harness exists to surface.
# - Weakest level is temporal (level 4, 33%): running totals and date boundaries.
# - Gold-SQL mutation kill rate is 100% (18 caught by the result comparator, 24 by error
#   classification), so the verifier provably catches the injected SQL errors it is meant to.
# Sample size: this is one run over a 20-question benchmark, so per-level rates (level 4
# is 1 of 3) are illustrative, not statistically strong. The harness is the deliverable;
# scale the benchmark for tighter numbers.
#
